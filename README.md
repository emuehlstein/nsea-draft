# NSEA Website Draft

Modern redesign draft for [nsea.com](https://nsea.com) — North Shore Emergency Association, a GMRS public service radio club serving Northern Illinois and the greater metro Chicago area since 1966.

- Single-page static site, no build step
- Content sourced from the existing nsea.com (repeaters, weekly net, meetings, membership, contacts)
- Deployed for review via GitHub Pages
